# Handoff

**State (2026-10-19T14:30Z):** foundation only. The data core, model registry and
unit suite are green; there is no UI yet. Hero art is being generated by a writer on
`slice/heroes`.

## What exists

- Toolbox scaffold: `AGENTS.md`, `docs/` (ARCHITECTURE, BOARD, TESTING, DECISION-LEDGER,
  GATE, BRIEF, CROSS-TOOL, WAY-OF-WORKING), `scripts/gate.sh`, `scripts/cos.mjs`.

  `api.ts` (URL + boundary validation), `average.ts` (null-aware aggregate),
  `units.ts`, `wmo.ts`, `cache.ts`, `geocode.ts`, `format.ts`.
- `tests/unit/`: 28 tests, green. `tests/fixtures/berlin-7d.json`: real capture,
  including three genuinely unavailable models.

## Traps already known

- Open-Meteo returns **nulls past a model's horizon**; never render them as 0.
- Some models intermittently return all-null (AIFS, GraphCast, BOM at capture).
- Multi-model variables are **suffixed**; single-model responses are not.
- No git remote; do not add one.
